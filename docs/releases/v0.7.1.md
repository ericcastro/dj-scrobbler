# DJ Scrobbler 0.7.1

## Casting is experimental — macOS only

**Casting is experimental and available on macOS only. Windows and Linux casting support is coming soon.** Casting remains disabled on Windows/Linux; installers for all platforms retain playback, tracklists, recognition, and scrobbling.

## Security fixes

- Resolve all 65 unique advisories reported by OSV-Scanner against the 0.7.0 dependency lockfile: 77 package/advisory findings across 14 affected package versions.
- Upgrade Electron to 43.8.4, electron-builder to 26.18.0, and electron-updater to 6.8.11, with patched transitive dependencies. macOS 12 compatibility is retained.
- Replace the vulnerable legacy ZIP extraction dependency through Electron's maintained extractor.
- Require a passing OSV scan before release builds. No advisories are suppressed and no dependency overrides are used.

OSV-Scanner 2.6.0 reports zero findings for the updated lockfile. This describes OSV's supported dependency scan, not a security certification of every bundled native component or live service.
